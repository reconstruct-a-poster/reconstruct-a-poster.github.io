Abstract

Automating academic poster generation from scientific papers remains challenging: existing LLM-based pipelines hallucinate layouts and produce visually defective outputs, while end-to-end image generation models yield non-editable raster images that fail to preserve dense scientific content. Yet researchers in practice rarely design posters from scratch but instead adapt existing templates.

In this paper, we present RAP, a multi-agent framework that retrieves and adapts real poster templates rather than generating layouts from scratch. We first construct PosterReverse-25K, the largest academic poster template dataset to date, by collecting over 25K posters from top-tier ML conferences and applying an automated derendering pipeline that converts poster images into structured templates. Built upon this, multiple specialized agents collaborate in a two-stage pipeline: a ParserAgent extracts structured metadata from the input paper; three RetrievalAgents then cooperate in a coarse-to-fine cascade, progressively narrowing candidates to a single best-matching template through categorical filtering, narrative matching, and aesthetic scoring; a MappingAgent produces a content-to-slot mapping, and deterministic rules execute all replacements, modifying slot text and images while leaving layout and styling untouched.

To address visual issues caused by filling (e.g., text overflow), an iterative ReviewerAgent refines visual quality through VLM-based critique and targeted style patches, with safety guards preventing destructive modifications. Experiments demonstrate that RAP produces posters with significantly more professional visual quality compared to the SOTA baselines, while maintaining full editability and fidelity closer to human-crafted exemplars.

Method

RAP is built on PosterReverse-25K — 25,435 paper–poster pairs derendered into structured HTML templates via layout detection, font-size estimation, design captioning, and MLLM reconstruction. On top of it, we explore two applications: template retrieval-based poster generation and post-training for vision-language models.

Inside the pipeline

ParserAgent

Parses LaTeX or PDF input into structured content—metadata, sections, and a figure registry—then classifies the paper into a domain/task/method taxonomy and distills its introduction into a structured summary used as the fingerprint for retrieval.

Beyond retrieval, the dataset also enables post-training: paper text and assets are extracted, design and layout instructions are derived from reference posters, and a VLM is fine-tuned with SFT followed by rendering-aware RL (GRPO) under rule-based and VLM-based rewards.
